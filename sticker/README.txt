スタンプ撮影スタジオ（ローカル版）
====================================

■ 起動
  このフォルダの index.html を Chrome か Edge にドラッグ（またはダブルクリック）するだけ。
  サーバーやインストールは不要です。

■ 同梱モデル
  5体ぶんのモデルが入っています。「モデル」タブのボタンを押すだけで読み込めます。
  sushifairy は「おすしのネタ」ボタンでマグロ / サーモン / 大トロ / たまご に切り替えられます
  （スタンプ1枚ごとに別のネタを使えます）。
  「ポーズ」タブにキャラごとの専用ポーズ（きほん・あいさつ・ダンスなど）があり、
  クリップのコマ送り＋ボーン微調整で自分だけのポーズも作れます。

■ モデルの読み込み
  「モデル」タブ →「📁 モデルフォルダを開く」で、
  sushihamster / sushifairy / recordolphin / kakapop / vibestar の
  .vrm / .glb が入っているフォルダ（Cドライブのどこでも OK）を選びます。
  サブフォルダの中も探します。
  Chrome / Edge ならフォルダを覚えるので、次回からは「前回のフォルダ」ボタンで開けます。

■ 文字（ぷっくり3D文字）
  文字は3Dの「風船」としてキャラと同じ空間に置かれます。
  ・素材：バルーン / ホログラム / クローム / ゼリー / くも などから選び、色は丸いボタンかカラーピッカーで自由に変更。
  ・形：「太らせる」「角の丸み」「ぷっくり」でふくらみ具合を調整。
  ・ステージ上の文字をドラッグで移動、「前後」でキャラの後ろにも回せます（O の穴からのぞく構図など）。

■ 動くスタンプ（APNG）
  「アニメ」タブでプレビュー再生しながら作れます。
  ・キャラの動き：ゆらゆら / ぴょんぴょん / ぷるぷる / くるくる / のりのり
  ・GLBキャラ（recordolphin / kakapop / vibestar）はポーズタブで選んだモーションがそのまま動きます
  ・文字の動き：ぷかぷか / ドキドキ / ゆれる / ジャンプ
  ・長さ(1〜4秒)・fps・ループ回数はスタンプ1枚ごとに保存されます
  書き出しは LINE アニメーションスタンプ仕様（APNG・最大320×270・20フレーム以内・300KB以下・
  main.png 240×240 APNG・tab.png 96×74 PNG）。300KBを超えると警告が出ます。

■ 保存について
  ・スタンプ一覧（ポーズ・表情・文字・カメラ）はブラウザに自動保存されます。
  ・前回のフォルダを開くと、スタンプで使っていたモデルが自動で読み込まれます。
  ・別のPCに移すときは「プロジェクト保存」で JSON に書き出してください。

■ フォルダの中身
  index.html   … アプリ本体
  lib/vendor.js … three.js / three-vrm / JSZip（オフライン用に同梱）
  models/*.js  … 同梱モデル（ダブルクリック起動でも読めるようbase64のJS形式）

■ ネット接続
  文字用のフォント（Google Fonts）だけネットから読み込みます。
  オフラインのときは PC に入っているフォントで表示されます。
