スタンプ撮影スタジオ（ローカル版）
====================================

■ 起動
  このフォルダの index.html を Chrome か Edge にドラッグ（またはダブルクリック）するだけ。
  サーバーやインストールは不要です。

■ モデルの読み込み
  「モデル」タブ →「📁 モデルフォルダを開く」で、
  sushihamster / sushifairy / recordolphin / kakapop / vibestar の
  .vrm / .glb が入っているフォルダ（Cドライブのどこでも OK）を選びます。
  サブフォルダの中も探します。
  Chrome / Edge ならフォルダを覚えるので、次回からは「前回のフォルダ」ボタンで開けます。

■ 保存について
  ・スタンプ一覧（ポーズ・表情・文字・カメラ）はブラウザに自動保存されます。
  ・前回のフォルダを開くと、スタンプで使っていたモデルが自動で読み込まれます。
  ・別のPCに移すときは「プロジェクト保存」で JSON に書き出してください。

■ フォルダの中身
  index.html   … アプリ本体
  lib/vendor.js … three.js / three-vrm / JSZip（オフライン用に同梱）

■ ネット接続
  文字用のフォント（Google Fonts）だけネットから読み込みます。
  オフラインのときは PC に入っているフォントで表示されます。
